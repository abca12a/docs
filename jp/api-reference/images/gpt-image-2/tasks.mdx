---
title: "画像タスクを取得"
description: "画像生成タスクのステータスと結果を照会します。"
openapi: "GET /tasks/{task_id}"
icon: "bars-progress"
---

非同期画像タスクを送信した後、返された公開 `task_id` を使用してステータスを照会します。公開タスク ID は `task_` で始まり、画像プール内部の `img_` ID は照会に使用できません。

## リクエスト

```bash
curl "https://api-direct.dimilinks.com/v1/tasks/task_xxx" \
  -H "Authorization: Bearer $DIMILINKS_API_KEY"
```

## 処理中のレスポンス

```json
{
  "task_id": "task_xxx",
  "status": "IN_PROGRESS",
  "progress": "50%",
  "fail_reason": "",
  "created_at": 1777080000,
  "finished_at": 0,
  "data": {
    "task_id": "task_xxx",
    "status": "in_progress",
    "data": []
  }
}
```

## 成功時のレスポンス

```json
{
  "task_id": "task_xxx",
  "status": "SUCCESS",
  "progress": "100%",
  "fail_reason": "",
  "created_at": 1777080000,
  "finished_at": 1777080060,
  "data": {
    "created": 1777080000,
    "task_id": "task_xxx",
    "status": "success",
    "data": [
      {
        "url": "https://lmage2.dimilinks.com/p/img/img_xxx/0?exp=1777166400000&sig=...",
        "file_id": "file_xxx"
      }
    ]
  }
}
```

## 画像 URL の形式

タスクが成功したら `data.data[].url` を読み取ります。外側の `data` は保存された生成レスポンスで、その中の `data` フィールドに画像レコードが入ります。

URL が `/p/img/` で始まる場合は、表示またはダウンロードする前に `https://lmage2.dimilinks.com` を補ってください。完全な `https://lmage2.dimilinks.com/p/img/...` URL はそのまま使用できます。署名と有効期限が URL に含まれるため、Bearer は不要です。

## 失敗時のレスポンス

```json
{
  "task_id": "task_xxx",
  "status": "FAILURE",
  "progress": "100%",
  "fail_reason": "アップストリームからエラーが返されました",
  "created_at": 1777080000,
  "finished_at": 1777080060
}
```

## ステータス

| ステータス | 意味 | 呼び出し元での推奨対応 |
| --- | --- | --- |
| `NOT_START` / `SUBMITTED` / `QUEUED` | 処理待ち | ポーリングを続けます。 |
| `IN_PROGRESS` | 生成中 | ポーリングを続けます。 |
| `SUCCESS` | 完了 | `data.data[].url` を表示します。 |
| `FAILURE` | 失敗 | `fail_reason` を表示し、ユーザーが再試行できるようにします。 |

画像タスクの照会には `GET /v1/tasks/{task_id}` だけを使用してください。削除済みの `/v1/images/tasks/{task_id}` は呼び出さず、画像プールの `img_xxx` を公開タスク ID として扱わないでください。
