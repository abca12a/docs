---
title: "Retrieve image task"
description: "Retrieve the status and result of an image generation task."
openapi: "GET /tasks/{task_id}"
icon: "bars-progress"
---

After submitting an asynchronous image task, use the returned public `task_id` to retrieve its status. Public task IDs use the `task_` prefix; the image pool's internal `img_` ID cannot be used for retrieval.

## Request

```bash
curl "https://api-direct.dimilinks.com/v1/tasks/task_xxx" \
  -H "Authorization: Bearer $DIMILINKS_API_KEY"
```

## In-progress response

```json
{
  "task_id": "task_xxx",
  "status": "IN_PROGRESS",
  "progress": "50%",
  "fail_reason": "",
  "created_at": 1777080000,
  "finished_at": 0,
  "data": {
    "task_id": "task_xxx",
    "status": "in_progress",
    "data": []
  }
}
```

## Successful response

```json
{
  "task_id": "task_xxx",
  "status": "SUCCESS",
  "progress": "100%",
  "fail_reason": "",
  "created_at": 1777080000,
  "finished_at": 1777080060,
  "data": {
    "created": 1777080000,
    "task_id": "task_xxx",
    "status": "success",
    "data": [
      {
        "url": "https://lmage2.dimilinks.com/p/img/img_xxx/0?exp=1777166400000&sig=...",
        "file_id": "file_xxx"
      }
    ]
  }
}
```

## Image URL formats

After the task succeeds, read `data.data[].url`. The outer `data` is the saved generation response, and its `data` field contains the image records.

If the URL starts with `/p/img/`, prefix it with `https://lmage2.dimilinks.com` before displaying or downloading it. A complete `https://lmage2.dimilinks.com/p/img/...` URL can be used directly; its signature and expiration are embedded, so no Bearer token is required.

## Failed response

```json
{
  "task_id": "task_xxx",
  "status": "FAILURE",
  "progress": "100%",
  "fail_reason": "The upstream provider returned an error",
  "created_at": 1777080000,
  "finished_at": 1777080060
}
```

## Status values

| Status | Meaning | Recommended caller action |
| --- | --- | --- |
| `NOT_START` / `SUBMITTED` / `QUEUED` | Waiting to be processed | Continue polling. |
| `IN_PROGRESS` | Generating | Continue polling. |
| `SUCCESS` | Completed | Display `data.data[].url`. |
| `FAILURE` | Failed | Display `fail_reason` and allow the user to retry. |

Use only `GET /v1/tasks/{task_id}` for image task retrieval. Do not call the removed `/v1/images/tasks/{task_id}` route or treat an internal `img_xxx` image ID as the public task ID.
