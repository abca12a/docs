A-series models use the unified `POST /v1/videos` endpoint with per-second billing; the resolution tier determines the per-second price. Tasks are asynchronous: creation returns a `task_id`, then use [Retrieve video task](/en/api-reference/videos/tasks) to poll status and download the result.

<Note>
  Video billing is per second: cost = per-second price × duration. Check `seconds`, `resolution`, and `aspect_ratio` against the limits below before submitting.
</Note>

## Endpoint

```http
POST https://api-direct.dimilinks.com/v1/videos
Content-Type: application/json
Authorization: Bearer <DIMILINKS_API_KEY>
```

## Text-to-video example

```bash
curl "https://api-direct.dimilinks.com/v1/videos" \
  -H "Authorization: Bearer $DIMILINKS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance2.5-A",
    "prompt": "Cinematic city night scene, a person walking along a wet street, steady tracking shot",
    "seconds": 8,
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'
```

Success response:

```json
{
  "id": "task_xxx",
  "task_id": "task_xxx",
  "object": "video",
  "model": "seedance2.5-A",
  "status": "queued",
  "progress": 0
}
```

## Model capabilities

| Item | `seedance2.0-A` | `seedance2.5-A` |
| --- | --- | --- |
| Positioning | Standard quality | New generation |
| Duration | 4-15 seconds | 4-30 seconds |
| Resolution | 480p / 720p / 1080p | 480p / 720p |
| Aspect ratios | 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / Auto | 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 |
| Defaults | 4s, 480p, 16:9 | 4s, 480p, 16:9 |

## Pricing

| Resolution | `seedance2.0-A` per second (¥) | `seedance2.5-A` per second (¥) |
| --- | ---: | ---: |
| 480p | 0.60 | 0.70 |
| 720p | 1.00 | 1.30 |
| 1080p | 1.80 | unsupported |

Cost = per-second price × `seconds`. Prices may change; use `GET /api/pricing` as the runtime source of truth.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | `seedance2.0-A` or `seedance2.5-A`. |
| `prompt` | string | yes | Video description; reference media with `@图N` / `@视频N` / `@音频N` placeholders, numbered from 1 by array position. |
| `seconds` | integer | no | `seedance2.0-A`: 4-15s; `seedance2.5-A`: 4-30s; default 4. |
| `resolution` | string | no | `seedance2.0-A`: `480p` / `720p` / `1080p`; `seedance2.5-A`: `480p` / `720p`; default `480p`. |
| `aspect_ratio` | string | no | See the capability table; default `16:9`. `seedance2.5-A` does not support `Auto`. |
| `references` | array | no | Reference media array, see below. |

## Reference media

Put media into the `references` array. Each `source` must be a public HTTPS URL the server can fetch directly:

```json
{
  "references": [
    { "type": "image", "role": "reference", "source": "https://cdn.example.com/character.png" },
    { "type": "video", "role": "reference", "source": "https://cdn.example.com/motion.mp4" },
    { "type": "audio", "role": "reference", "source": "https://cdn.example.com/dialogue.mp3" }
  ]
}
```

Limits:

- `seedance2.0-A`: images ≤ 9, videos ≤ 3, audios ≤ 3, total ≤ 12; reference videos 1.8-15s each, total ≤ 15s; reference audio 2-15s.
- `seedance2.5-A`: images ≤ 30, videos ≤ 10, audios ≤ 10, total ≤ 50; reference videos ≤ 30s each and in total; reference audio 2-30s.
- Single file ≤ 100 MB; reference video pixels roughly 640×640 to 4K.
- `role` can be `reference` / `first_frame` / `last_frame`: videos and audios only use `reference`; first/last frames must be images.

## First/last frame mode (only `seedance2.0-A`)

- First and last frames must be submitted in pairs, as images only, and cannot be mixed with ordinary references.
- Frame mode supports only the `Auto` aspect ratio.
- `@图N` and `@图片N` are equivalent in prompts; every submitted reference must be referenced in the prompt, unreferenced media is rejected.

## Next step

Save the `task_id` from the creation response, then poll with [Retrieve video task](/en/api-reference/videos/tasks) until `completed` before downloading.
