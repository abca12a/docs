DimiLinks 提供与 OpenAI、Anthropic 使用习惯一致的统一 API。一把 Bearer 密钥就能调用 Claude、GPT 等文本模型，并提交 `gpt-image-2` 图片任务和 `grok-imagine-video` 视频任务。

<Note>
  图片和视频生成都建议走异步链路：提交任务后用任务接口轮询结果。
</Note>

## 请求地址

DimiLinks 的模型 API 统一使用以下请求地址：

```text
https://api-direct.dimilinks.com/v1
```

OpenAI 兼容接口可直接把它填写为 base URL。Anthropic 官方 SDK、Claude Code 等原生客户端会自动追加 `/v1/messages`，因此这类客户端的 `base_url` 要填写为 `https://api-direct.dimilinks.com/`，避免请求变成错误的 `/v1/v1/messages`。两种配置使用同一域名和同一把 Bearer 密钥。

## 推荐链路

```text
POST https://api-direct.dimilinks.com/v1/chat/completions          # 对话（OpenAI 兼容，推荐编程使用）
POST https://api-direct.dimilinks.com/v1/messages                  # 对话（Anthropic 原生协议）
POST https://api-direct.dimilinks.com/v1/images/generations?async=true  # 图片：异步提交
POST https://api-direct.dimilinks.com/v1/videos/generations             # 视频：异步提交（默认即异步）
GET  https://api-direct.dimilinks.com/v1/tasks/{task_id}                # 图片 / 视频任务通用查询
```
